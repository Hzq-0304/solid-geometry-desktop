# Solid Geometry Desktop

Tauri + React + TypeScript + Three.js desktop skeleton for a solid geometry workspace.

## Prerequisites

- Node.js
- Rust toolchain
- Tauri system dependencies for Windows

## Commands

```powershell
cd C:\solid-geometry-desktop
npm install
npm run dev
```

Desktop app:

```powershell
npm run tauri dev
```

Production build:

```powershell
npm run build
```

The current app shell includes a left toolbar, central Three.js viewport, right properties panel, and bottom status bar.
